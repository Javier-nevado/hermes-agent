# Human Writing Style — Anti-AI Detection

> Use this style for ALL client content: blog articles, newsletters, landing pages.

## Why This Exists

AI detectors (ZeroGPT, GPTZero, etc.) flag content based on predictable patterns.
This skill ensures our content reads like a real person wrote it — because it should.

## Core Principles

### 1. Vary sentence length dramatically

Mix it up. Some sentences should be 3 words. Others should be longer, more winding
sentences that reflect how a person actually thinks through an idea — not perfectly
structured, but natural and readable.

### 2. Ditch the AI tells

NEVER use these words/phrases (they're AI giveaways):
- "Moreover", "Furthermore", "Additionally", "In conclusion"
- "It's important to note that", "It's worth mentioning that"
- "In today's [X] landscape", "In the world of [X]"
- "Delve into", "Navigate", "Leverage" (when used as buzzwords)
- "Revolutionize", "Transform", "Streamline"
- "Whether you're a [X] or a [Y]"
- "Let's [verb] into [topic]"

### 3. Write like you're explaining to a friend

Use conversational tone. Contractions are good. Fragments are fine.
"You'll need to file by the 10th working day" beats "It is imperative that submissions
are completed prior to the tenth working day."

### 4. Include specific, verifiable details

Real dates, real numbers, real names, real URLs. AI tends to generalize;
humans tend to be specific.

Bad: "Penalties can be significant"
Good: "Miss a deadline and you're looking at €700 minimum. We've seen businesses hit with €3,500 fines for repeat offences."

### 5. Have opinions and personality

Don't be neutral on everything. Take a stance.
"Honestly, most Maltese importers we've spoken to didn't even know about the €700 threshold" 
is better than "Many businesses may be unaware of the reporting threshold."

### 6. Imperfect structure

- Not every section needs the same number of paragraphs
- Not every list needs exactly 3 or 5 items
- It's OK to have a one-sentence paragraph
- It's OK to go on a tangent briefly

### 7. Real-world framing

Open with scenarios, not definitions:
- "If you imported €800 worth of goods last month, you already need to file Intrastat."
- NOT: "Intrastat is a statistical reporting requirement mandated by EU regulation..."

### 8. Use formatting like a human would

- Bold for emphasis on key points (not every heading)
- Bullet lists when they genuinely help readability
- NOT: every other sentence bolded for "scannability"
- Occasional italics for nuance

## Writing Process

1. Write the first draft normally
2. Read it aloud — does it sound like a robot? Fix it
3. Check for AI tells (see section 2)
4. Add at least 2-3 specific details per section
5. Vary sentence length — if 3 sentences in a row are similar length, break the pattern
6. Add a personal/opinion touch in the intro and conclusion

## Self-Check Before Delivery

- [ ] No "Moreover/Furthermore/Additionally" anywhere
- [ ] Sentence lengths vary (count words in 5 consecutive sentences — should be different)
- [ ] At least one colloquial/casual phrase per section
- [ ] Specific numbers/dates/names used (not vague references)
- [ ] Has a clear opinion or point of view
- [ ] Opening line is NOT a definition or "In today's world"
- [ ] Run through ZeroGPT if possible — target: under 20% detection
